# Kairoseth AI Transparency

**EU AI Act Readiness for WordPress**

Kairoseth AI Transparency is the first WordPress-first product in the Kairoseth Extensions portfolio. It is designed to help WordPress site owners identify supported AI integrations, maintain a local AI Systems Registry, implement clear AI-interaction disclosures, and produce evidence-backed transparency readiness records.

> Status: repository bootstrap. No public stable plugin release exists yet.

## Product identity

- Commercial name: **Kairoseth AI Transparency**
- SEO descriptor: **EU AI Act Readiness for WordPress**
- Technical slug: `ai-transparency`
- WordPress.org target slug: `kairoseth-ai-transparency`
- Commercial model: useful Free + Custom
- Public repository: Free edition
- Custom customer work: separate private repositories

## Important boundary

This software provides technical readiness, workflow and evidence tooling. It does **not** certify or guarantee legal compliance with the EU AI Act or any other law.
